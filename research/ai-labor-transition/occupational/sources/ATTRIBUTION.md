# Phase 2 sources and attribution

Raw files are exact publisher/official aggregate bytes, compressed deterministically. Names identify SHA-256 of **uncompressed** bytes. `config/sources.json` records every URL, hash and permission; `sources/receipts/` retains genuine capture timestamps outside deterministic payloads. A new receipt does not change economic/methodological values.

1. **SOC 2018**: U.S. Bureau of Labor Statistics on behalf of OMB/SOCPC, final November 2017 structure for January 2018. Downloaded from the official U.S. Census Bureau distribution after the BLS endpoint returned 403. Public U.S. federal statistical data; titles/hierarchy preserved.
2. **O*NET® 31.0 Database**, August 2026, by USDOL/ETA and the National Center for O*NET Development, used under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The [database license](https://www.onetcenter.org/license_db.html) and [Resource Center license](https://www.onetcenter.org/license.html) are pinned with their original bytes. Crosswalks retain their source URLs/hashes. Task text is unmodified; structures/ranks/links were added by World Inflation Lens. USDOL/ETA has not approved, endorsed or tested these additions. O*NET® is a USDOL/ETA trademark.
3. **GPTs are GPTs** data: Eloundou, Manning, Mishkin and Rock; source repository at commit `0471612fef3cc22b74fb884d27bff9dbd3770582`. MIT notice, copyright and permission text are retained as a pinned raw source file. Cite [the paper](https://arxiv.org/abs/2303.10130). Underlying O*NET 27.1-derived task content retains O*NET attribution; MIT does not remove that obligation. Human/GPT annotation categories, weights and original text are preserved; normalized fields and ranks are additions.
4. **Working with AI**: Tomlinson, Jaffe, Wang, Counts and Suri (2025), [paper](https://arxiv.org/abs/2507.07935), Microsoft repository commit `c94a07c52fb1d88ca5d221388f06d10e1bd6d2fe`, data v1.1. [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) license text is retained. Original IWA/occupation data are preserved; normalized code matches, source-specific ranks and comparison flags are additions.
5. **Anthropic Economic Index initial release**, February 10, 2025, Handa et al., dataset commit `4e5f69fab13a9c3f7d0dcc31a6f893a9818738f6`, folder `release_2025_02_10`. Cite [initial research](https://www.anthropic.com/news/the-anthropic-economic-index) and [publisher data](https://huggingface.co/datasets/Anthropic/EconomicIndex). Both root and release-specific README explicitly assign data CC-BY and code MIT; CC-BY version is unspecified. The dataset-card MIT marker is not applied to the data. Historical O*NET task text remains attributed to USDOL/ETA; its exact database release is not supplied. Normalized formatting, exact-text candidate links and taxonomy relations are additions; no occupational usage-share or automation-rate inference is added.

Accepted licenses permit redistribution/adaptation and commercial use with the stated notices/attribution. No restricted raw data, secrets, user identities or confidential conversation records are present. No contractual API access or rate-limit circumvention is used. License snapshots are evidence for these pinned releases, not blanket permission for future releases. Deferred ILO/IMF/Felten/Stanford data are **not** included; their licensing and mapping gates remain in the methodology document.
