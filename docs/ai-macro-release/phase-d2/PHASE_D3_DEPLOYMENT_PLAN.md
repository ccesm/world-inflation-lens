Do not deploy or merge this D2 candidate. It intentionally contains a release-hold stub instead of the full economic snapshot.

Record its scope, date and attribution. Do not substitute a different series or silently reduce the twelve-indicator contract.

## Smallest deployment

Prepare a small production PR only after these gates close and the owner explicitly authorizes the PR. Include the current-main-based UI patch, permitted frozen assets and updated release evidence; no research branch merge, dependency redesign or automated refresh. Attach exact code/artifact hashes, reviewed changed-file list and current main SHA. Owner approval to merge/deploy is separate from local acceptance; main pushes invoke the existing normal Pages workflow.

Before merge record the then-current known-good main and Pages artifact. After explicit approval, merge through the normal protected workflow and inspect build/verify/deploy status. Do not enable new schedules, send custom notifications or publish unattended updates.

## Smoke checks and monitoring

Check direct `#/research/ai-macro` navigation/reload under `/world-inflation-lens/`, EN/ZH, both themes, mobile/desktop, accurate last-observation vs snapshot dates, source links, one on-demand history request and its byte/hash validation. Check AI CapEx, AI Infrastructure, AI Labor, Signal Engine, data workspace and all routed modules. Check no console errors or economic runtime requests. A failed history fetch must preserve the validated summary and offer manual retry. No source update should overwrite the last-valid artifact.

## Rollback

If new integration is faulty, stop acceptance and ask for the owner's rollback authorization. Revert the specific integration commit with a new commit; do not reset/force-push or erase unrelated subsequent bot updates. Let the existing main Pages build publish the revert. Restore the previously reviewed immutable snapshot pointer only if its distribution permission and hashes remain valid. Verify legacy routes, version, snapshots and deployment health after rollback. Record failure and corrective acceptance; do not automate rollback or begin D3 from this document.
