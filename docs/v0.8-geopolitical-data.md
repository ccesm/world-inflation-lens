# V0.8 — Geopolitical Inflation Transmission

本模块研究地缘压力是否通过军费、供应链、能源与食品进入经济，进而改变美国通胀和美元长期购买力；不预测战争，不计算综合风险评分或事件概率。

## Definitions that must survive updates

- GPR is a newspaper-coverage index, not war probability. Acts measures reporting of realized acts, not an event count. Recent GPR/GPRT/GPRA are not spliced with historical GPRH. Pre-1985 coverage stays unavailable.
- SIPRI footnote 44 states that **all U.S. figures are financial-year data**, October of the previous year through September of the stated year. This overrides the generic calendar-year description. World aggregates are calendar-year data. Never interpolate annual spending into monthly data.
- SIPRI Excel percentage fractions are multiplied by 100. U.S. real figures are millions, world real figures billions, both constant 2024 USD. The additional “2025 (current prices)” column is deliberately excluded from the constant-price series. Government-spending share uses general government, not federal spending alone. Workbook source color flags and footnotes remain in each snapshot.
- World military/GDP is not a time series in this import; no country ratios are averaged. The global spending series is SIPRI's official aggregate, not a sum with unknown coverage.
- FAO is upstream international commodity pricing; U.S. food CPI is downstream consumer inflation. Separate scales preserve that distinction. Recent FAO meat observations mix actual and projected source prices, potentially revising meat and total. No immediate pass-through or causal contribution is asserted.
- All changes use exact preceding calendar periods. Missing denominators and nonpositive denominators for percentage changes produce missing results, not interpolation. Military five-year change uses the constant-price series.
- Historical bands identify selected windows already discussed in the eight attributed episodes. Overlap is context, not causal attribution or a future forecast.

## Refresh and revision history

The existing weekly Monday **14:23 UTC** Action checks monthly GPR, GSCPI and FAO alongside existing FRED/World Bank data. Ordinary main pushes deploy committed snapshots. **SIPRI is intentionally excluded from weekly downloads** and needs an annual manual review of the version, units/base year, U.S. footnote and source terms.

Python 3.12 with `scripts/requirements-external.txt` (`xlrd==2.0.2`, `openpyxl==3.1.5`) is needed only for actual workbook ingestion. Browser code has no keys, APIs or Python dependency. `npm install`, `npm run dev`, `npm run build`, `npm run verify` work with Node and committed snapshots. `WIL_PYTHON` optionally selects the interpreter.

Initial/annual review uses downloaded files in an ignored input directory:

```sh
python -m pip install -r scripts/requirements-external.txt
node scripts/import-external.mjs --input-dir .refresh/external --output-dir .refresh/external-candidate
```

Review the candidate report and file hashes before copying a newly approved annual snapshot. This importer only stages candidates. For an independently re-extracted workbook omit `gpr-extracted.json` / `sipri-extracted.json` from the input directory. Those optional files support offline test fixtures, not network production ingestion.

Routine refresh downloads into memory/temporary files, validates the entire candidate, compares all historical values, runs parser tests, then uses one rollback-protected transaction for all eight output files. Build and full verification execute inside that transaction; any failed download, validation, test, write or build prevents publication and restores originals when applicable. The separate SIPRI snapshot is validated but not replaced. GitHub commits and deploys only after checks pass. No force pushes. Rollback does not try to restore disposable `dist`; a failed run never uploads it.

Checks cover exact source/series identity and units, monthly/annual frequency, complete chronological date slots, duplicate and truncated data, future dates, nonnegative GPR/FAO, valid negative GSCPI, Excel percent formatting, separate real-price units and fiscal/calendar bases. Removed dates fail; unusual withdrawals over 5% fail. Source dates cannot regress. Revisions, added, filled and withdrawn values are accounted for. Full external-series changes are retained in the latest 30 ledger runs; older versions remain in Git history.

**Initial revisions:** This is the first site import, so all four families establish a baseline; no previous site snapshot exists from which to claim revisions. Independently, NY Fed's August→September 2026 columns show **147 revised historical observations**, zero withdrawals. July changes from **0.79 to 0.94**; the new August reading is **1.06**. This source-vintage comparison is preserved in `import-report.json` and GSCPI metadata and is clearly separated from site update counts.

## Deterministic summary rules

1. Find the latest month with GPR, GSCPI, WTI and FAO Total finite values. Do not forward-fill.
2. If it is older than three months, or any preceding-month value is missing, show insufficient recent data.
3. GSCPI, WTI and FAO all increasing: describe concurrent supply/price pressures.
4. Otherwise WTI and FAO both increasing: describe energy/food price pressure.
5. Otherwise: describe mixed observed channels.

GPR is displayed alongside those changes as context, never used to attribute causality. The summary does not infer a geopolitical cause, persistence, future CPI, war likelihood or investment signal. Annual military data and daily/weekly market observations are separate. 5y5y compensation includes risk/liquidity premia and is not a 30-year forecast.
