# V1.0 Dual-Dollar consolidation

This report covers the feature branch `codex/v1-dual-dollar-architecture`. V1.0 local acceptance passed on October 2, 2026. The package version was set to 1.0.0 only after the full production-browser suite passed. Production is not changed by this work.

## Architecture and preservation

1. **Starting main:** `f6ca94cfdc039e18b856a6a334980102fdc0e1ec`, validated snapshot after the V0.13 code checkpoint `da90067`. Origin was fetched before changes and checked again during acceptance; no newer snapshots were present at those checks.
2. **Feature branch:** `codex/v1-dual-dollar-architecture`; existing uncommitted work was continued. Main was not used for implementation.
3. **Architecture:** one registry-linked `researchArchitecture.js` owns stages, four themes, primary/secondary roles, route context, labels, evidence references and planned gaps. Protected source definitions and snapshots remain separate. The map describes an explanatory reading order, with policy, financing, exchange-rate and Treasury-demand feedbacks.
4. **Dual-Dollar:** Home and Dollar distinguish domestic purchasing power from international dollar use. The distinction is visible before the map and observations; neither outcome establishes the other.
5. **Structural forces:** Fiscal Conditions → existing Fiscal/CBO/debt tools; Productive Capacity → AI/Productivity and investment/infrastructure proxies; External Supply Shocks → GPR/GSCPI/energy/food/SIPRI; Dollar System → existing Digital Money research and explicit gaps.
6. **Inflation transmission:** CPI, core PCE, shelter, food, energy, compensation and ULC link to the existing tools. Upstream shocks, cost/wage transmission and persistent inflation are distinguished; no equal weighting or aggregate score is created.
7. **Policy response:** existing Fed Funds, Fed assets and M2 research remains. M2 is not money printing, M2 and the Fed balance sheet are not added together, and real yields are market/financing evidence as well as policy-transmission context.
8. **Market validation:** Monitor presents exact-date nominal DGS10 minus real DFII10, including the matched date, individual input freshness, missing inputs, older shared dates and a calculation table. The difference is inflation compensation with risk/liquidity effects, not a pure inflation forecast. T5YIFR is explicitly a different maturity concept; the broad dollar is market context, not a dominance index.
9. **Domestic outcome:** Purchasing Power, Since 1971, CPI/history and conditional scenarios retain their original calculations. Home keeps a compact CPI purchasing-power chart and links to the full tools.
10. **International outcome:** partial publication evidence is marked honestly. Reserve shares, international debt/lending, foreign Treasury holdings, invoicing, payments, alternative reserves and funding coverage remain planned where not integrated. No synthetic dominance score or placeholder numbers.
11. **Homepage before/after:** the former long framework, detailed previews and repeated evidence modules are replaced by hero → two dollar questions → compact map → four dated observations → four themes → research links → purchasing power/history. See the measured results below.
12. **Modules relocated/relinked:** full AI/Productivity, Digital Money, External Shocks, Fiscal/CBO, scenarios, Since 1971, history, global map/comparisons, Data Workspace, Updates and Sources retain their routes. Research retains the three horizons/four unweighted scenarios. Dollar retains the existing indicator-specific descriptive bands in an expandable section (`#/dollar?focus=research-environment`).
13. **V0.13 preservation:** raw data, registry/contract, freshness/release calendars, time semantics, status/notification infrastructure, refresh/rollback/publishing workflow and original calculation utilities are unchanged. CBO actual FY1962–2025 and projection FY2026–2056, solid/dashed styles, source vintage/assumptions, annual tables/CSV and FRED/OMB denominator distinctions remain.
14. **Routes:** the original 21 legal routes and six primary sections are retained. The original route parser is unchanged; old metric, group, topic, episode, country, year, series, range and focus query behavior is covered by tests.
15. **Accessibility:** a hash-preserving skip link focuses main; navigation focuses the destination heading after lazy content resolves; focused section links open details where appropriate. Primary active parents use `aria-current=location`, exact current pages use `page`; compact research context and back-to-map links are added.

## Reproducibility

Use the README production-preview/browser commands. Optional Chrome and Playwright paths are environment variables, not hard-coded runtime dependencies. Browser JSON, logs, CSV downloads and screenshots are local test artifacts under `.refresh/`, ignored by Git. The suite validates every legal route across twelve display combinations and checks query state, exact-date Treasury arithmetic, keyboard focus, calculators, CBO boundaries/vintage/CSV values, Workspace exports, date precision, manual/fixed evidence, Data Health and System Status. Mocked status responses are explicitly labeled in the report and are not evidence of actual Gmail delivery or a workflow run.

V0.13 protection can be audited with:


The expected diff for these protected paths is empty. The feature branch must be reviewed independently before any separately authorized merge or deployment.
